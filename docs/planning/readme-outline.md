# README outline (12 points)

> Working document, originally Swedish. Converted to Markdown so it lives with the project.

## README-upplägg

1. Titel och kort beskrivning: Vad modden gör i en mening, med en skärmdump eller gif när det finns. Vi skall ligga inom "Rekommenderad ålder: 13+" 


2. Funktioner: Textchatt med NPC:er och djur, humörlägen, vapen utan att döda,  omgivningskännedom, nakenhet i procent 

3. Krav: GTA V Enhanced, ScriptHookVDotNet Enhanced, .NET Framework 4.8 och en AI-leverantör (lokal Ollama eller molntjänst). 

4. Installation: Steg för steg, från nedladdning av release till kopiering av filer. 

5. Konfiguration: Hur `PedAndPaw\_AI.ini` används, med en tabell över de viktigaste nycklarna. 

6. Google Gemini API key for default AI, eller lokal LLM modell, eller valfri LLM-kompatibel API.

7. Molntjänster: Hur man lägger in API och varnar för kostnader. 

8. Egna karaktärer: Länk till `docs/PROFILES.md`. 

9. Bygga från källkod: `dotnet build` och vart DLL:en hamnar. 

10. Plugins: Länk till `docs/PLUGINS.md` och en kort beskrivning av händelserna. 

11. Kända begränsningar: Till exempel att svar kan ta några sekunder och att kvaliteten beror på vald modell. 

12. Licens och bidrag: MIT, samt riktlinjer för pull requests.
